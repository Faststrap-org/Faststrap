# Generated SaaS

`showcase/generated_saas.py` is a smaller polished SaaS landing reference in Faststrap.

It shows a more intentional visual direction than the basic demo tier, with dark-mode-first styling and HTMX interactions.

## Gallery

![Generated SaaS in light mode](../assets/showcase/generated-saas-light.png)

![Generated SaaS in dark mode](../assets/showcase/generated-saas-dark.png)

## What It Shows

- `create_theme()` brand palette (violet/cyan)
- custom atmosphere CSS (shell gradients, glassmorphism)
- `NavbarModern` + `ThemeToggle` + cookie persistence
- hero with live code console (architectural geometry)
- logo trust rail
- `FeatureGrid` (6 cards)
- how-it-works 3-step visual
- `PricingGroup` (3 tiers) with featured tier
- `TestimonialSection` (3 cards)
- newsletter CTA with `LoadingButton`
- `FooterModern`
- `ActiveSearch` with `/api/search` endpoint
- `/api/subscribe` endpoint with `ToastContainer` feedback
- full dual-mode: dark default, `ThemeToggle` to light
- `PageMeta` for SEO

## Why It Matters

Generated SaaS is useful for teams evaluating whether Faststrap can support:

- compact SaaS marketing pages
- dark-mode-first brand expressions
- conversion-oriented launch layouts
- HTMX-first interactions with toast feedback
