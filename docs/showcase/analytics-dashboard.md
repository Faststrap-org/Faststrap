# Analytics Dashboard

`showcase/analytics_dashboard.py` is a compact analytics/dashboard reference in Faststrap.

It demonstrates whether the framework can produce premium, non-generic-Bootstrap dashboards when component-first guidance is followed strictly.

## Gallery

![Analytics Dashboard in light mode](../assets/showcase/analytics-dashboard-light.png)

![Analytics Dashboard in dark mode](../assets/showcase/analytics-dashboard-dark.png)

## What It Shows

- a focused analytics dashboard composition
- theme-aware light and dark presentation
- polished surface styling over Bootstrap-native layout
- `DataTable`, `Chart`, `MetricCard`, and `StatCard`
- `FilterBar` for dashboard filtering
- `ThemeToggle` with cookie persistence

## Why It Matters

Analytics Dashboard is useful for teams evaluating whether Faststrap can support:

- internal analytics tools
- KPI-heavy operational dashboards
- compact data surfaces without custom JavaScript
- dark-mode-first product interfaces
